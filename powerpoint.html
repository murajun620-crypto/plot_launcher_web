← PlotLauncher Web

グラフをPowerPointへ送信する

PowerPoint内の作業ウィンドウでPlotLauncher Webを使い、「PowerPointへ送信」を押すと、選択中のスライドに図を挿入できます。Pythonのインストールは不要です。

アドイン定義（XML）をダウンロード

現行のPowerPoint（Windows / Mac / Web）の画像挿入APIを使用します。SVG対応環境ではベクター画像、それ以外は指定した解像度のPNGを挿入します。導入方法はOfficeの版と学校のアカウント設定で異なります。

学校で学生へ配布する場合

Microsoft 365管理者に上のXMLを渡し、Officeアドインの集中展開で対象の学生へ配布してください。学生はPowerPointの「ホーム → アドイン」からPlotLauncher Webを開きます。

下の手動登録は試用・開発確認用です。学校での継続配布には管理者による展開を使用してください。アドインの利用が学校の設定で制限されている場合も、管理者への確認が必要です。

まず手動で試す

PowerPoint Web
  1. PowerPoint Webで編集可能なプレゼンテーションを開きます。
  2. 「ホーム → アドイン → その他の設定（More Settings）」を開き、「マイ アドインのアップロード」を選びます。旧UIでは「挿入 → アドイン → マイ アドイン → マイ アドインの管理」にあります。
  3. ダウンロードした powerpoint-manifest.xml を選択してアップロードします。
  4. PlotLauncher Webの作業ウィンドウが表示されます。

MicrosoftのWeb版登録手順。ブラウザのデータを消したり別のブラウザに変えたりすると再登録が必要です。

MacのPowerPoint
  1. Finderの「移動 → フォルダへ移動」で ~/Library/Containers/com.microsoft.Powerpoint/Data/Documents を開きます。
  2. wef フォルダを作成し、その中へ powerpoint-manifest.xml をコピーします。
  3. PowerPointを終了して再起動し、「ホーム → アドイン」からPlotLauncher Webを選びます。

MicrosoftのMac版登録手順

WindowsのPowerPoint
  1. 試用用のフォルダに powerpoint-manifest.xml を保存し、フォルダの「プロパティ → 共有」で自分がアクセスできる共有フォルダにします。共有先のパス（\\PC名\フォルダ名）を控えます。
  2. PowerPointの「ファイル → オプション → トラストセンター → トラストセンターの設定 → 信頼できるアドイン カタログ」で、その共有パスを追加し「メニューに表示」を有効にします。
  3. PowerPointを再起動し、「ホーム → アドイン → 詳細設定 → 共有フォルダー」でPlotLauncher Webを追加します。

MicrosoftのWindows版登録手順。学校の端末では管理者による集中展開を推奨します。

図を挿入する

  1. 送信先のスライドを選択し、PowerPoint内のPlotLauncher WebでExcel / CSVを読み込みます。
  2. プリセット・フォント・注釈を設定し、プレビューが「更新済み」になるまで待ちます。
  3. 「PowerPoint接続済み」を確認して「PowerPointへ送信」を押します。

表示倍率にかかわらず、図の寸法（ラベル・余白を含む）を保って挿入します。挿入するのは一枚の画像です。編集可能な別のパネルラベルが必要な場合は、PPTX保存を使用してください。

通常のブラウザで作成中の図は「設定を保存」でJSONを保存し、アドインで同じデータとフォントを読み込み、「設定を開く」で復元できます。

画像をコピーして貼り付ける

通常のブラウザでは「画像をコピー」を押し、PowerPointでCtrl＋V（MacではCommand＋V）を押します。PNGの解像度は画面の選択値（標準1200 dpi）を使用します。クリップボード書き込みが許可されない環境ではPNGを保存して挿入してください。

単独のブラウザから、PC上で開いているPowerPointに直接アクセスすることはできません。直接送信はPowerPointのアドイン内で使用してください。
