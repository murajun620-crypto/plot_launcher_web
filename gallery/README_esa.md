# PlotLauncher ギャラリーのesa掲載

esaの投稿先は未指定のため、投稿前の完成原稿です。

1. すぐ表示する場合はesa.mdをesa本文に貼る。画像は公開ギャラリーから表示される。
2. esaに画像も保管する場合はesa_upload.mdを本文に使い、assetsフォルダのPNGをesaへアップロードし、各画像リンクをesaのURLに置き換える。
3. ダウンロードリンクと参考資料はそのまま使える。

article.mdとindex.htmlはローカル閲覧用。figuresは高解像度出力、dataは模擬入力、projectsはアプリで再開できるプロジェクト。2アプリの記事・素材・ZIPは独立。図には模擬データという説明を添えたまま掲載する。
