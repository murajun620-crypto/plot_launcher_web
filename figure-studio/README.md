# Figure Studio Web v0.3

論文のFigureを、元の編集プロジェクトと一緒に組み立てるWebアプリです。GitHub Pagesで配信できる静的HTML/JavaScriptで、ビルドやサーバー処理は不要です。

## 使い方

1. PlotLauncher／MiFiToの「Figure Studioへ送る」で図と元プロジェクトを直接追加・関連付けできます。一般の画像は「図を追加」、ドロップ、クリップボードからPNG / JPEG / WebP / SVGを配置します。
2. 上部のツールで文字・線・矢印・長方形・楕円を作成します。文字はダブルクリックまたはF2で編集します。線・矢印を選ぶと、右の「矢印の先端」で始点・終点それぞれの形をアイコンから選べます。種類は「なし・三角・開いた矢印・ステルス・ひし形・円」です。幅・長さを調整でき、円は「サイズ」で大小を変更します。円はどのサイズでも真円です。
3. 紙内の空白または灰色の余白をドラッグして、複数の図を囲って選択します。Shift併用で追加、Escで囲み選択をキャンセルできます。ツールバーで整列・等間隔・重なり順を変更できます。
4. 左サイドバーのサムネイルを選択しEnterで、そのFigureの次にキャンバスを追加します。「＋」またはCtrl+Mも使えます。Ctrl（Macでは⌘）クリックで複数選択、Shiftクリックで範囲選択、サイドバー内のCtrl+Aで全Figureを選択します。選択したサムネイルをドラッグし、挿入位置の線へドロップするとまとめて順番を変更できます。Escでドラッグを中止します。
5. サムネイルの上下キーでFigureを切り替え、Shift併用で範囲選択します。Ctrl+Dで選択したFigureを複製、DeleteまたはBackspaceで削除します。削除時の確認ダイアログはなく、Ctrl+Zで戻せます。全Figureを削除した場合は空白のFigureを1枚残します。キャンバス左上に現在のFigure番号、上部の名前欄にFigure名を表示します。
6. キャンバス下部の「画質」でプレビューを **1 / 1/2 / 1/4** から選べます。「1」は元画像の解像度、「1/2」「1/4」は縦横それぞれをその比率にした軽量表示です。拡大して確認するときは「1」、大きな画像を多く扱うときは「1/2」「1/4」を使ってください。設定はこのブラウザに保存されます。
7. Ctrl+Sで**全Figure・画像・関連付けた元プロジェクト**を一つの `.figurestudio` ファイルへ保存します。書き出しは現在のFigureが対象です。プレビュー画質の設定にかかわらず、保存・書き出しには元画像を使います。

初回の作例はすべて模擬データです。研究データではありません。

## 元アプリで編集

PlotLauncher／MiFiToで「Figure Studioへ送る」を押すと、表示中のグラフ・画像と現在のプロジェクトをまとめて渡します。手動のファイル保存や関連付けは不要です。開いているFigure Studioが見つかればそのタブへ追加し、見つからなければ新しく開きます。MiFiToは現在編集中の画像が対象です。

追加した図を選んで「元を編集」を押すと、Web版に元プロジェクトを渡します。修正後に元アプリの「Figureへ反映」を押すと、位置・サイズ・パネルラベルを維持して更新します。元プロジェクトも一緒に更新されます。手元の画像には従来の「関連付け」で `.plotproject` / `.mifito` を登録する方法も使えます。

両Webアプリへ適用する連携アダプターを同梱し、適用版でプロジェクトと編集結果の往復を確認しています。別の配信先やアプリのコピーへ導入する方法は `integration/README.md` に記載しています。未適用の旧版では未接続の案内と元プロジェクトのダウンロードが表示されます。通常起動時の元アプリの操作はそのままです。

## 保存と出力

バージョン右の「更新確認」で新しい版を確認できます。更新がある場合は「更新する」に変わり、作業中の全Figureをブラウザに保存してから再読み込みします。保存に失敗した場合は更新を中止して画面を保持します。

- ブラウザ内に自動保存します。同じブラウザ・プロファイルで再開できます。長期保存や別PCへの移行には `.figurestudio` を使用してください。
- SVG：文字・線・矢印と元SVGを保持します。
- PNG：300 / 600 / 1200 dpi。指定の実寸に対応するピクセル数とpHYs解像度情報を出力します。
- PDF：ブラウザの印刷を使用します。「PDFに保存」、倍率100%、余白なし、ヘッダー/フッターなしを選んでください。
- プレビューの「1/2」「1/4」は編集画面だけに適用します。元画像・関連付けたプロジェクトは保持し、SVG・PNG・PDFの書き出しでは元画像を使用します。出力の画素数はPNGのDPI指定など、それぞれの出力設定で決まります。
- データをサーバーへ送る処理はありません。Webアプリ間の連携はブラウザ内のタブ間通信です。

## ver0の範囲

- 1プロジェクト最大100 Figure。画像は1枚100 MB、プロジェクト保存・読込は400 MBまで。
- 文字の書式はテキストボックス全体へ適用します。文字単位の混在書式、数式組版、PPTX読込/書出しは未対応です。
- PDFは印刷経由。フォントは使用中のPCのフォントを利用し、書き出し先で置換される場合があります。
- SVGの外部参照・スクリプト・アニメーションは除去します。
- 画像の通常リサイズは縦横比を保持します。グループ変形・自動配置では文字サイズを維持するため、必要に応じて余白を調整してください。
- 別PC間の自動同期・共同編集はありません。

## 配信・開発

GitHub Pagesでこのディレクトリをそのまま配信できます。相対URLのみなのでサブディレクトリ配信にも対応します。ローカル確認はHTTPサーバーで開いてください（file://直開きではES modules・保存・Web連携を利用できません）。外部ライブラリ依存はありません。

```sh
node --test tests/*.test.mjs integration/*.test.mjs
```

`tests/performance.html` は20画像＋80文字＋20矢印を毎フレーム移動する独立診断です。実際のアプリや巨大画像の性能保証ではありません。

サムネイルは最大320 pxの画像としてキャッシュします。変更確定後に画面内のFigureから順次更新し、ドラッグ中には作り直しません。
