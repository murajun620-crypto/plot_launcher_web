# Figure Studio Web v0.4.0

論文のFigureを、元の編集プロジェクトと一緒に組み立てるWebアプリです。GitHub Pagesで配信できる静的HTML/JavaScriptで、ビルドやサーバー処理は不要です。

[統合画面を開く](https://murajun620-crypto.github.io/plot_launcher_web/figure-studio/)と、上部のStudio／PlotLauncher／MiFiToタブで作図・画像編集・レイアウトを切り替えられます。一度開いた編集画面はタブ切替で再読み込みせず、そのまま保持します。図をStudioへ送ると、受信完了後にStudioタブへ戻ります。

## 使い方

1. 統合画面のPlotLauncher／MiFiToタブで図を作り、トップバーの「Figure Studioへ送る」で図と元プロジェクトを追加・更新します。MiFiToの複数画像は「まとめてStudioへ送る」で一括追加・更新できます。反映後はStudioタブへ自動で戻ります。一般の画像は「図を追加」、ドロップ、クリップボードからPNG / JPEG / WebP / SVGを配置します。
2. 上部のツールで文字・線・矢印・長方形・楕円を作成します。文字はダブルクリックまたはF2で編集します。線・矢印を選ぶと、右の「矢印の先端」で始点・終点それぞれの形をアイコンから選べます。種類は「なし・三角・開いた矢印・ステルス・ひし形・円」です。幅・長さを調整でき、円は「サイズ」で大小を変更します。円はどのサイズでも真円です。
3. 紙内の空白または灰色の余白をドラッグして、複数の図を囲って選択します。Shift併用で追加、Escで囲み選択をキャンセルできます。ツールバーで整列・等間隔・重なり順を変更できます。
4. 左サイドバーのサムネイルを選択しEnterで、そのFigureの次にキャンバスを追加します。「＋」またはCtrl+Mも使えます。Ctrl（Macでは⌘）クリックで複数選択、Shiftクリックで範囲選択、サイドバー内のCtrl+Aで全Figureを選択します。選択したサムネイルをドラッグし、挿入位置の線へドロップするとまとめて順番を変更できます。Escでドラッグを中止します。
5. サムネイルの上下キーでFigureを切り替え、Shift併用で範囲選択します。Ctrl+Dで選択したFigureを複製、DeleteまたはBackspaceで削除します。削除時の確認ダイアログはなく、Ctrl+Zで戻せます。全Figureを削除した場合は空白のFigureを1枚残します。キャンバス左上に現在のFigure番号、上部の名前欄にFigure名を表示します。
6. キャンバス下部の「画質」でプレビューを **1 / 1/2 / 1/4** から選べます。「1」は元画像の解像度、「1/2」「1/4」は縦横それぞれをその比率にした軽量表示です。拡大して確認するときは「1」、大きな画像を多く扱うときは「1/2」「1/4」を使ってください。設定はこのブラウザに保存されます。
7. 「保存」またはCtrl+Sで**全Figure・画像・関連付けた元プロジェクト**を一つの `.figurestudio` ファイルへ保存します。初回にフォルダーとファイル名を選び、次回からは同じファイルへ上書きします。書き出しは現在のFigureが対象です。プレビュー画質の設定にかかわらず、保存・書き出しには元画像を使います。

最初の保存ではフォルダーとファイル名を選び、次回から「上書き保存」またはCtrl+Sで同じファイルを更新します。保存ボタン右のメニューから「名前を付けて保存」も選べます。「開く」で選んだプロジェクトも上書き保存できます。対応ブラウザでは保存先をブラウザ内に保持し、再読み込み後も復元します。ファイルへのアクセス権限はブラウザが管理し、必要に応じて再許可を求めます。未対応ブラウザや保存先情報を保持できない環境では、ダウンロードまたは保存先の選び直しになります。

初回の作例はすべて模擬データです。研究データではありません。

サムネイルを並べ替えると、名前の先頭にある「Fig. 1」「Figure 1」などの番号も現在の順番へ振り直します。追加・削除・複製時も同様で、名前・キャンバス左上の番号・書き出しファイル名が揃います。「Figure 1 — 結果」の補足タイトルや、番号を含まない独自の名前は保持します。並べ替えのUndo/Redoでは番号も一緒に戻ります。

## 元アプリで編集

PlotLauncher v2.4.20／MiFiTo v1.9.4では、統合画面の各アプリのトップバーにある「Figure Studioへ送る」を使います。表示中のグラフ・画像と現在のプロジェクトをまとめて渡すため、手動のファイル保存や関連付けは不要です。Studioの図をダブルクリックすると対応する編集タブへ切り替わり、反映後は元の図を更新してStudioへ戻ります。操作ボタンと接続・送信結果はヘッダー内に表示します。今回の対応版はFigure Studio v0.4.0・PlotLauncher v2.4.20・MiFiTo v1.9.4です。

MiFiToの複数画像は、統合画面のトップバーにある「まとめてStudioへ送る」で同期できます。プロジェクト・画像ごとの識別情報を `.mifito` に保存し、複数のFigureへ配置した同じ画像も位置を保って更新します。変更のない画像はスキップし、更新・追加・変更なしの枚数をヘッダー内に表示します。未追加の画像は、直接送信では受信先で開いているFigureへ、編集画面からの反映では元の画像を開いたFigureへ追加します。一括反映の変更はCtrl+Zの1回で戻せます。MiFiTo側で削除した画像があっても、Studio側の配置は自動削除しません。

MiFiTo v1.9.4では、プレビュー上の「Studioに貼る画像サイズ」で「画像本体のサイズを指定」をオンにし、幅または高さをmmで指定できます。設定は対象の画像だけに適用し、「全画像に適用」でまとめて揃えられます。画像本体の縦横比を保ち、カラーバー・画像外のラベル領域を除いた寸法を、単体送信・一括送信の両方で使用します。既存画像に初めてサイズを指定したときは指定寸法を採用し、その後の再編集ではStudio上で手動変更した倍率を維持します。位置は変わりません。指定しない画像は従来どおり追加時に用紙へ収め、更新時は配置サイズを維持します。この設定はStudio送信専用で、通常のファイル保存の寸法は変えません。

追加した図を選んで「元を編集」を押すと、Web版に元プロジェクトを渡します。修正後に元アプリのトップバーで「Figure Studioへ送る」を押すと、位置・パネルラベルを維持して元の図を更新します。PlotLauncherのSVGとサイズ指定済みのMiFiTo画像は配置倍率を維持し、サイズ未指定のMiFiTo画像などは配置サイズを維持します。元プロジェクトも一緒に更新されます。手元の画像には従来の「関連付け」で `.plotproject` / `.mifito` を登録する方法も使えます。

v0.3.2から、PlotLauncherの「Figure Studioへ送る」と実寸情報のあるSVGファイルの追加は、元の寸法で配置します。たとえば軸領域4 × 3 cmはFigure上でも40 × 30 mmです。右側のW/Hは軸ラベル・余白を含む画像全体の寸法なので、軸の寸法より大きくなります。用紙より大きい図も自動縮小しません。再編集でラベルや余白が変わった場合は画像の外寸を調整して軸の倍率を保ちます。Figure Studio上で手動変更した倍率も維持します。既に配置済みの図は勝手にサイズを変更しません。元の実寸で置き直す場合は再送信してください。PNGのクリップボード貼り付けは実寸保持の対象外です。

Studio単独画面でも、図のダブルクリック／「元を編集」で同じ配信元（origin）の開いているPlotLauncher／MiFiToを再利用します。Studioへの反映が完了した同じプロジェクトなら、その後の編集を保持して接続し、描画エンジンを起動し直しません。Studioを再読み込みした後も、図を開けば残っている編集タブへ再接続できます。通信の再試行で同じプロジェクトを何度も開き直すこともありません。

別の内容や未反映の編集が開かれている場合は、置き換えずに案内します。元の編集を残して進めるときはStudioの「新しい編集タブで開く」を選べます。連携中の未反映編集は、トップバーからStudioへ送るか、切替時に表示される「未反映の編集を取り消す」で最後に同期した状態へ戻せます。

両Webアプリへ適用する連携アダプターを同梱し、適用版でプロジェクトと編集結果の往復を確認しています。別の配信先やアプリのコピーへ導入する方法は `integration/README.md` に記載しています。未適用の旧版では未接続の案内と元プロジェクトのダウンロードが表示されます。通常起動時の元アプリの操作はそのままです。

## 単独で使う

統合画面と単独画面は同じHTML・JavaScriptを読み込みます。別実装のコピーは作らず、各アプリの編集・保存機能を共通で使用します。PlotLauncher／MiFiToを単独で起動したときはStudio送信ボタンを表示しません。

- [MiFiTo単独](https://murajun620-crypto.github.io/Microscopy_figure_tools_web/)

## 保存と出力

バージョン右の「更新確認」で新しい版を確認できます。更新がある場合は「更新する」に変わり、作業中の全Figureをブラウザに保存してからStudio画面を再読み込みします。統合画面では開いているPlotLauncher／MiFiToの編集画面を保持します。保存に失敗した場合は更新を中止して画面を保持します。

- 「保存」／Ctrl+Sは、初回に保存先のフォルダーとファイル名を選び、以後は上書き保存します。保存ボタン右の▽から「名前を付けて保存」を選ぶと、別の保存先へ変更できます。「開く」で選択した `.figurestudio` ファイルも、そのまま上書き先になります。
- 保存先はプロジェクトごとにブラウザ内へ記憶し、同じブラウザでの再読み込み・再開後も復元します。ブラウザが求めた場合は書き込み許可を再確認します。ファイルへの直接保存に対応しないブラウザでは、ダウンロードとして保存します。
- ブラウザ内に自動保存します。同じブラウザ・プロファイルで再開できます。長期保存や別PCへの移行には `.figurestudio` を使用してください。
- SVG：文字・線・矢印と元SVGを保持します。
- PNG：300 / 600 / 1200 dpi。指定の実寸に対応するピクセル数とpHYs解像度情報を出力します。
- PDF：ブラウザの印刷を使用します。「PDFに保存」、倍率100%、余白なし、ヘッダー/フッターなしを選んでください。
- プレビューの「1/2」「1/4」は編集画面だけに適用します。元画像・関連付けたプロジェクトは保持し、SVG・PNG・PDFの書き出しでは元画像を使用します。出力の画素数はPNGのDPI指定など、それぞれの出力設定で決まります。
- データをサーバーへ送る処理はありません。Webアプリ間の連携はブラウザ内のタブ間通信です。

## ver0の範囲

- 1プロジェクト最大100 Figure。画像は1枚100 MB、プロジェクト保存・読込は400 MBまで。
- 文字の書式はテキストボックス全体へ適用します。文字単位の混在書式、数式組版、PPTX読込/書出しは未対応です。
- PDFは印刷経由。フォントは使用中のPCのフォントを利用し、書き出し先で置換される場合があります。
- SVGの外部参照・スクリプト・アニメーションは除去します。
- 画像の通常リサイズは縦横比を保持します。グループ変形・自動配置では文字サイズを維持するため、必要に応じて余白を調整してください。
- 別PC間の自動同期・共同編集はありません。

## 配信・開発

GitHub Pagesでこのディレクトリをそのまま配信できます。相対URLのみなのでサブディレクトリ配信にも対応します。ローカル確認はHTTPサーバーで開いてください（file://直開きではES modules・保存・Web連携を利用できません）。外部ライブラリ依存はありません。

```sh
node --test tests/*.test.mjs integration/*.test.mjs
```

`tests/performance.html` は20画像＋80文字＋20矢印を毎フレーム移動する独立診断です。実際のアプリや巨大画像の性能保証ではありません。

サムネイルは最大320 pxの画像としてキャッシュします。変更確定後に画面内のFigureから順次更新し、ドラッグ中には作り直しません。
