# Figure Studio Web v0.1 検証記録

## 確認済み

- 自動テスト：モデル・ショートカット・Web連携の45件が合格。
- 実ブラウザ：複数Figureを一つのプロジェクトとして保存し、開き直して復元。
- 左サムネイル：表示・選択強調・クリック切り替え・図変更後の更新・上下キー切り替え・Ctrl+DによるFigure複製を確認。
- 実ブラウザ：Alt → 5 → L、Alt → 3、Alt → 4、Ctrl+Shift+> の操作。
- ローカル配信したアダプター適用版：PlotLauncher Web・MiFiTo Webの双方で、元プロジェクトの読込から編集結果をFigureへ戻す往復。
- PNG書き出し：180 × 135 mm、600 dpiで4252 × 3189 pxを確認。
- 独立した模擬ベンチマーク：20画像・80文字・20矢印、計120要素の移動で平均フレーム間隔16.68 ms。

## 検証範囲

ベンチマークは小さな模擬画像を事前に読み込んだ測定用画面です。実アプリの全操作、巨大画像、保存・書き出しの速度を表すものではありません。16.68 msは測定環境での結果で、別のPC・ブラウザでも同じ速度になるという保証ではありません。

Web連携の往復確認はローカルのアダプター適用版で実施しました。公開先の接続確認は、配信状態とキャッシュ更新を含めて別途扱います。ブラウザ・OSが先に処理するショートカットには環境差があります。
