# PlotLauncher Web

Excel / CSVの測定データをブラウザ内で処理し、17種類のプリセットで描画してSVG・PNG・PDF・PPTXで保存できます。

[Webアプリを開く](https://murajun620-crypto.github.io/plot_launcher_web/)

[グラフギャラリー](https://murajun620-crypto.github.io/plot_launcher_web/gallery/) — 全15種・16作例。模擬データの生成条件、CSV、設定済みプロジェクト、PNG・SVG・PDF、esa用本文を収録しています。

[学生向けマニュアル](https://murajun620-crypto.github.io/plot_launcher_web/manual/) — [簡易版](https://murajun620-crypto.github.io/plot_launcher_web/manual/quick.html)と[詳細版](https://murajun620-crypto.github.io/plot_launcher_web/manual/detailed.html)があります。操作部・ダイアログの拡大画像、マウス操作を示すGIF、データの並べ方と練習用CSVを用意しています。[esa投稿用一式を保存](https://murajun620-crypto.github.io/plot_launcher_web/manual/manual.zip)

アプリのインストールは不要です。ファイルを選び、X列とY列を指定してください。
Excelのセル範囲をコピーし、「01 データ」→「データを貼り付け」→入力欄にCtrl/Command＋V→「読み込む」でも利用できます。
列名の有無を自動判定し、チェックで変更できます。貼り付けたデータもプロジェクトに保存されます。
共通Xと複数Yを自動で系列に追加し、読み込み直後から描画します。CV/LSV・CA・CPの繰り返しX列はXYペアとして扱います。
軸・系列・注釈・背景・各プリセットと図上編集の数値欄は、小数の入力に対応しています。
全プリセットで、X軸・Y軸・右Y軸の単位を分類別リストから選べます。時間・長さ・波数・エネルギー・電位・電流・電流密度・速度など58種類と、「自動（列名から）」「単位なし」「自由入力」を用意しています。図上の軸ラベルをダブルクリックした設定画面でも選択できます。単位の表記のみを変更し、データの数値は換算しません。既存の単位・任意の入力・数式表記はプロジェクトに保持します。
軸の目盛り数値は小数桁を揃え、ゼロだけは常に「0」と表示します。「03 軸とサイズ」で主・副目盛りの間隔を指定し、それぞれの「自動」チェックで自動設定に戻せます。副目盛りの表示も切り替えられます。目盛り数値のダブルクリックでも設定できます。対数軸の副目盛りは自動配置です。
対数軸では、各軸の「目盛りの表記」で累乗（10ⁿ）と数値（0.01、0.1、1、10、100、1000）の表示を選べます。目盛りのダブルクリックからも切り替えでき、X・Y軸それぞれの設定をプロジェクトに保存します。
軸ラベル・単位・凡例・注釈のμは、`\micro`で立体表示できます。`\microm`はμm、`\microA`はμA、`$\micro$`は数式内の立体μです。`$`で囲まずに入力でき、省略記法のまま設定・プロジェクトに保存されます。
初期表示はデータ未選択です。サンプルは「サンプルデータを使う」を押した場合だけ表示します。設定JSONはデータを含みません。

## マイプリセット（v1.9.0）

1. データを開いて、軸・単位・系列・色・注釈などを調整します。
2. 「プリセット」→「現在の設定を登録」で名前を付けて登録します。
3. 別のデータを開き、「マイプリセット」のリストから選ぶと、登録した設定を適用します。

v1.9.1以降は「管理・共有」からも登録できます。リストで「新規登録（現在の設定）」を選び、名前を入力して「現在の設定を登録」を押します。登録済みの名前を選ぶと、名前変更・削除に切り替わります。登録が0件でも名前を入力でき、データ未読み込みの場合は登録に必要な操作を案内します。

ページの更新・ブラウザの再起動後も、同じブラウザ・プロファイルに残ります。「管理・共有」で名前変更・削除・全件のJSON書き出し・読み込みができます。サイトデータの削除やプライベートブラウズ終了で失われる場合があるため、必要な設定はJSONでも保存してください。他のPCや学生にも、このJSONで共有できます。

プリセットには測定データやフォントファイルを含みません。系列の列は同じ列名を優先し、名前が違う場合は同じ位置を使います。必要な列やフォントがない場合は案内を表示します。独自フォントを使う場合は先に読み込んでください。登録した図は、通常のプロジェクト保存でもデータと設定をまとめて保持できます。

同名登録は明示的に上書きを選択します。JSON読み込みでは同じ内容を重複追加せず、同名で内容が異なる場合は番号を付けて両方を残します。ブラウザへの登録は最大100件・合計2 MB、読み込むJSONは4 MB以内です。内蔵の17プリセットはそのまま使えます。

## 研磨レート

プリセット「研磨レート」は、横軸 `Polishing time (min)`、縦軸 `Removal thickness (μm)`、線＋丸マーカー、線形軸、左上の凡例を初期設定にします。系列の初期色は順に青・赤・黒です。両軸の最小値は0、最大値と目盛り間隔はデータに合わせて自動設定します。系列数・列・名前・色は変更できます。
誤差棒は各系列の「線・マーカー・誤差」で誤差列を選んで表示します。近似線・数式、プロジェクト保存、シートの一括／個別設定にも対応します。

## Waviness

「Waviness」はRoughnessの描画処理を再利用し、横軸 `Polishing time (min)`（timeのtは小文字）、縦軸 `Waviness (nm)`、線＋マーカー、Y軸対数を初期設定にします。Y軸の範囲・目盛り間隔・凡例位置は自動に戻します。誤差棒、近似線、左右Y軸、単位リスト、プロジェクト保存、複数シートの一括／個別設定に対応します。

## 軸ラベルの余白（v1.9.3）

全プリセットでX・Y・右Y軸ラベルの初期余白をB案の2 ptに統一しました。目盛数字がある場合は数字の外側、ない場合は枠線からの余白になります。スペクトルだけに加算していた6 ptは撤去しています。3Dの表示上のY量にも同じ値を適用します。
「ラベル余白」で変更でき、保存済みのプロジェクト・設定・マイプリセットの指定値やドラッグ位置は保持します。

## エラーバー

グラフ種別「一般」「Roughness」「研磨レート」「Waviness」では、「02 系列」→各系列の「線・マーカー・誤差」で指定します。

- **±値**：上下共通の誤差幅の列を選びます。
- **正・負の誤差幅**：上方向と下方向の幅を別々の列で指定します。どちらも0以上の値です。例：Y＝10、正の幅＝2、負の幅＝1なら、下端9・上端12です。
- **最小・最大値**：下端・上端のY値を直接指定します。最小値 ≤ Y ≤ 最大値となる列を選びます。

空欄・非数値の誤差がある点は、データ点を残して誤差棒だけを省略し、画面に通知します。誤差の指定はプレビューと全保存形式に反映され、設定JSON・プロジェクト・シート間の一括設定にも保存されます。

## 近似線と数式

「02 系列」→各系列の「近似線」で、直線・多項式（2〜6次）・指数・対数・べき乗を選べます。
直線の「原点を通る直線」をオンにすると切片を0に固定し、オフでは傾きと切片を求めます。
「数式を表示」で系列ごとに表示を切り替え、数式は図上でドラッグ移動・ダブルクリック編集できます。「線・数式の表示」で線種・色・線幅・文字サイズ・係数の有効桁数（2〜15桁）を調整します。

近似はオフセットを適用した有効なX/Y値に対する最小二乗法です。軸の表示範囲外の点も計算に含み、誤差棒を重みには使いません。指数はlog(Y)、べき乗はlog(X)とlog(Y)で回帰し、対数近似は自然対数ln(X)を使います。対数・べき乗はX>0、指数・べき乗はY>0の点を使い、除外した点数を通知します。式の表示だけを丸め、描画には計算時の精度を使います。[近似式の種類について（Microsoft）](https://support.microsoft.com/en-us/office/trendline-options-in-office)

設定・プロジェクト・複数シートの一括／個別設定に保持し、各シートのデータから再計算してPNG・SVG・PDF・PPTXに出力します。
近似が計算できない場合は元のデータを残して理由を表示します。保存は設定を修正するか近似を「なし」にして行います。一括保存では計算できないシートを保存結果に通知します。
対象はXY形式のグラフです。XPS Fit・粒径ヒストグラム・棒グラフ・Raman 3Dの専用機能は従来どおり使用できます。

## 左右で異なるY軸

グラフ種別「一般」「Roughness」「研磨レート」「Waviness」で、「02 系列」→「使用するY軸」を系列ごとに「左軸」「右軸」から選びます。
右軸の系列があると「03 軸とサイズ」に右Y軸の設定が表示され、ラベル・単位・範囲・主目盛り・副目盛り・線形／対数を左軸と別々に指定できます。
軸の色は軸線・目盛線・目盛数値・ラベルに適用します。autoで各軸の最初の系列に合わせ、カラーパネルから個別にも選べます。

右軸もプレビューのラベル・目盛りをダブルクリックして編集でき、ラベルはドラッグで移動できます。凡例は左右の系列を元の順番でまとめます。
エラーバー・系列の表示切り替え・背景・注釈・各保存形式にも対応し、設定JSON・プロジェクト・複数シートの一括／個別設定に保持します。
データ座標の注釈は左軸（右軸のみの図では右軸）を基準にします。

## 複数シートのプレビューと一括保存

Excelに複数シートがある場合は、プレビュー上の「◀」「▶」で切り替えます。シート名・現在の番号を表示し、左側のシート選択も同期します。
プレビューのシート切り替え横にある「設定：一括／個別」で、グラフ設定の適用範囲を選びます。

- **一括**：表示中の軸・系列・色・サイズ・注釈などを全シートで共通に使います。どのシートから変更しても全シートに反映します。一括へ切り替えると、その時点で表示している設定を適用します。
- **個別**：一括設定から切り替えた時点の見た目を引き継ぎ、その後はシートごとの調整を保持します。

どちらのモードでも全シートを一括保存できます。ヘッダー行はシート別に保持し、モードと各設定をプロジェクトにも保存します。新規データは「一括」が初期設定です。以前のプロジェクトは既存のシート別設定を保つため「個別」で開きます。列名が異なる場合は同じ位置の列を使用します。
「全シートを一括保存」から形式と保存先を選びます。ファイル名にはシート番号とシート名を付け、フォルダ保存では個別ファイル、ダウンロードでは1つのZIPにまとめます。PNG・SVG・PDF・PPTXを複数選択できます。
空白シートや描画できない項目はスキップし、保存結果に表示します。「中止」を押すと、処理中のファイルが完成したところで停止します。

左上にバージョンを表示します。未保存のデータや設定があると、タブやウィンドウを閉じたりページを更新する際にブラウザ標準の確認を表示します。
「プロジェクトを保存」でデータと設定をまとめて保存すると確認を解除します。図の書き出しや設定のみの保存では、プロジェクト全体は未保存として扱います。

初回起動にはインターネット接続が必要です。Pyodide・計算ライブラリはjsDelivr、Excel用パッケージはPyPIから取得します。
測定データのアップロードやアクセス解析の処理はありません。

## フォント

欧文用Liberation Sansと日本語用Noto Sans JPを同梱しています。SIL Open Font License 1.1はassets/fonts/Liberation-OFL.txt、assets/fonts/OFL.txtにあります。

Arialを使う場合は、表示オプションの「手元のフォントを読み込む」で利用するPCのArialを選んでください。日本語フォントも選択できます。フォントはブラウザ内だけで使用します。

CV/LSV、CA、CP、EDX、XPS Survey/Core/Fit、XAFS、Raman Spectrum、AFM Section、ヒストグラム、一般、Roughness、棒グラフ、Raman 3Dに対応。各種別に適した軸ラベルと単位を設定します。

Ctrl/Command＋ホイールでプレビューを25〜400%へ拡大・縮小できます。注釈の選択・Delete削除・複製・端点移動・整列・取り消しに対応し、PNGの標準解像度は1200 dpiです。PPTXはSVGの図と編集できるパネルラベルを含む空白スライドです。

各プリセットの設定JSONを復元できます。開いているExcel/PowerPointへの直接接続は、保存ファイルの読み込み・ダウンロードに置き換えています。


## 背景色と透明度のプレビュー

- プレビューの作業背景は、18 px周期のグレーのチェッカーボードです。透明な部分の確認用で、保存する図には含みません。
- 背景色を選ぶと透明背景を解除し、色をプレビューと出力に反映します。背景不透明度0の状態から色を選んだ場合は1に戻します。
- 不透明度0は透明背景、不透明度が0より大きい場合はその値で描画します。「図全体の背景色を使用」をオフにしても選択した色・不透明度は保持し、オンにすると再使用します。
- 全15プリセットで同じ背景処理を使用します。枠内の背景がオフの場合は、図の余白と軸領域で不透明度を揃えます。枠内の背景をオンにすると、指定した色・不透明度を別に重ねます。3Dの面も背景の色や透明度を遮らないようにします。
- 画面の案内・エラー・Web版の説明は、機能と設定を直接説明する文面に統一しました。


## プレビューからの編集（v1.1.0）

各系列の「描画」チェックで表示を切り替えます。設定は保持され、非表示の系列は凡例と保存する図にも含みません。
線・点・棒、軸ラベル・数値目盛り、凡例・注釈・枠線・目盛り線・グリッド、背景をダブルクリックして設定できます。
一つの目盛り数値にカーソルを合わせると、その軸の数値全体をハイライトします。
図全体と枠内の背景は、それぞれ色・不透明度・オン／オフを指定できます。プロジェクト保存で両方の設定と系列の表示状態を保存します。
