# PlotLauncherのマニュアルをesaに掲載する

PlotLauncherの簡易版と詳細版だけで完結する本文・画像・GIFの一式です。

## 公開しているマニュアル

- [簡易版](https://murajun620-crypto.github.io/plot_launcher_web/manual/quick.html)
- [詳細版](https://murajun620-crypto.github.io/plot_launcher_web/manual/detailed.html)
- [一式のダウンロード](https://murajun620-crypto.github.io/plot_launcher_web/manual/manual.zip)

## esaへの掲載

1. `quick.md` を「PlotLauncher 簡易マニュアル」、`detailed.md` を「PlotLauncher 詳細マニュアル」として別々の投稿にします。
2. `assets/` の画像・GIFを添付し、本文の画像リンクをesaの添付URLに置き換えます。`esa_media_map.csv` で、各記事が使う添付を確認できます。
3. 本文の `quick.md`・`detailed.md` へのリンクを、作成したesa記事のリンクに置き換えます。
4. 画像やGIFが小さい場合は、添付ファイルを開いて拡大できるリンクも添えます。GitHub Pages版には画像の拡大と＋・−、GIFの再生ボタンがあります。
5. esaプレビューで画像・GIF・リンクを確認し、学生に共有します。

`examples/` の3つのCSVも添付してください。人工の練習用データで、測定結果ではありません。

## 画像とGIFについて

画面全体、操作部、ダイアログを使い分けています。GIFは実画面の状態に案内用のカーソル・クリックの輪・ドラッグ経路を重ねた操作ガイドです。連続録画した動画ではありません。

## ファイルの内容

`quick.md` と `detailed.md` が投稿用の本文、HTML・CSS・JavaScriptがブラウザ閲覧用、`assets/` が添付素材です。掲載手順や確認記録は学生向け本文とは別にあります。
