# esa投稿用マニュアル一式

## 収録内容

- `01-common.md`：共通操作。開く・保存・コピー・プロジェクトでの再開。
- `02-plotlauncher.md`：グラフ作成。プリセット、系列、軸、注釈、背景。
- `03-mifito.md`：画像編集。校正、トリミング、スケールバー、連番ラベル、一括保存。
- `assets/`：公開中のアプリを操作して撮影したスクリーンショット23枚と操作GIF8本。
- `index.html`：画像・GIFを含めて読めるマニュアル。
- `media_manifest.json`：撮影対象のバージョン、GIFの場面・表示時間。
- `esa_media_map.csv`：添付する画像・GIFと、使う記事の対応表。
- `review_notes.md`：操作・収録ファイル・表示の確認記録（掲載担当者向け）。

投稿先チームとカテゴリは未定です。esaへの投稿は行っていません。

## 確認する

ブラウザから [GitHub Pagesの画像付きマニュアル](https://murajun620-crypto.github.io/plot_launcher_web/manual/) を開けます。上部の「esa投稿用一式（ZIP）」から、本文と画像・GIFをまとめて保存できます。

ZIPを展開し、`index.html`をブラウザで開いてください。画像をクリックすると拡大できます。GIFは「操作を再生」を押すと動き、「静止画に戻す」で止められます。インターネット接続なしでも本文と収録画像を読めます。

## esaへの掲載手順

1. 3本の記事を作成し、それぞれ対応するMarkdown本文を貼り付けます。共通操作を先に掲載すると、相互リンクを設定しやすくなります。
2. 各記事で使用する画像・GIFを添付します。対応するファイル名は本文と `esa_media_map.csv` で確認できます。
3. **`assets/ファイル名` の画像参照を、esaが生成した添付画像URLへ置き換えます。** ローカルのパスを貼り付けるだけでは、esa上に画像は表示されません。
4. 本文中の `01-common.md` などへのリンクを、掲載した記事のURLへ置き換えます。
5. esaのプレビューで、画像・GIF・表・チェックリスト・相互リンクを確認してから、学生へ共有します。

画像は本文の挿入位置にドラッグ＆ドロップして添付する方法も使えます。esaの画像添付・Markdownの扱いは [esa公式ガイド](https://docs.esa.io/posts/49) を参照してください。本文で同じ画像を再利用している箇所は、同じ添付URLを使えます。

ローカルプレビューは確認済みですが、投稿先が未定のためesa上での表示確認はまだ行っていません。チームURLと掲載先が決まったら、添付URLへの置換と掲載確認を行います。

## 撮影と更新

2026年10月4日時点の公開版、PlotLauncher Web v1.2.0 / MiFiTo Web v1.1.0を使用しています。サンプルデータと模式画像だけで撮影し、実験データや個人のファイルは使っていません。

GIFは、実際の操作の途中・完了画面を撮影し、読み取れる時間で順番に表示しています。連続したマウス移動を録画した動画ではありません。UIや数値を合成して再現した画面ではありません。

アプリが更新された場合は、まずファイル操作、ボタン名、校正・共通反映の範囲を確認し、必要な場面を撮り直してください。`frames/` と作成用スクリプトは作業フォルダに保持し、配布用ZIPには含めていません。
